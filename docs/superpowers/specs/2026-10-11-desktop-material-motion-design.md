# 桌面首页材质与动效精修

用户确认评审中的三项：背景与文字关系、卡片材质细节、拨牌与展开动效。设计北极星：产品是主角，光线退到文字之外，拨牌与展开像同一件有重量的物体。

- 只面向桌面浏览器，视觉覆盖从 901px 起，验收 1280×720、1440×900、1920×1080。
- 背景沿用原图和 Gaussian 蒙版，在上方文字区域增加平滑的局部暗场，不添加运动光效。
- 原卡片尺寸、弧线、产品图标、素材、按钮及内容保持。底栏略收紧，按画面的冷暖微调石墨表面，用 4px 的轻微接触暗部柔化上下接合；缩小远距离投影，保留接触阴影和键盘焦点。独立评审指出最初 16px 全色过渡像灰带，浅色主题还出现白边，因此缩窄并减淡。
- 桌面吸附采用按时间计算的临界阻尼，保留逐张切换和边界阻力。拖动中途接管正在运动的牌组时从当前位置继续。
- 打开、产品切换、返回沿用原生 Web Animations 与图片接力，统一桌面节奏，退出快于进入。转场收尾逐渐交给自动播放演示；减少动态效果仍直接显示内容。
- 不增加依赖，不提交、不推送、不部署。原有窄屏视觉与运动参数保留。

验收：前后桌面截图、一次独立存量视觉评审（不评分）、主 Agent 实际完成三轮拖动→打开→切换→返回，并检查快速连按、首尾、自动播放、转场清理和焦点归还；再检查脚本语法、入口同步和 Git 差异空白。

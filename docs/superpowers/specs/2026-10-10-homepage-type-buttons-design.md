# 首页文字与按钮精修

用户已在五方案对照页后确认实施推荐组合：Exat 文字层级、Unseen 平面按钮、Jimmy Nelson 深色对比。属于保留式精修，DESIGN_VARIANCE 6、MOTION_INTENSITY 4、VISUAL_DENSITY 4。

现状：系统无衬线字体，石墨背景与品牌淡紫，C 弧形横向拨牌，卡片与 Dock 保留真实产品图标。导航有带圆点的填充框，标题有装饰底线，详情页多种填充和圆角按钮同权。元信息、路由、产品目录和演示已有且可用。

实施：保留字体家族，区分标题与正文，校准中文行距及英文产品名；桌面标题与说明建立对齐的双栏，窄屏自然叠放。移除装饰标题色块与导航凸起框。文字入口用细下划线反馈；主卡操作与详情主 CTA 使用无阴影平面胶囊；次要操作用文字或轻底色，详情标签使用移动细下划线。采用短箭头移动和轻微按压，减少动效时静止。正文尺寸提高，深浅模式均保持可读对比。

保留：原产品图标、品牌点缀、所有产品资料、导航标签、URL、C 拨牌几何和拖动逻辑、Dock 入口、高斯背景、键盘焦点与详情演示。无需新框架、依赖或付费服务。

验证：同步资源哈希及旧入口；1280×720、1440×900、375×667、320×640 浏览器观察，无横向溢出，首屏导航、主卡和 Dock 可见；实点详情、切换标签、播放停止、Esc 返回、键盘拨牌、关于导航及深浅模式。保存截图。真机触摸和跨浏览器不在本次验证内。

# 首页字体精修 · 2026-10-13

用户确认方向：现代简洁，标题舒展，字重更克制。

本次以字体和阅读层级改善现有产品作品集：让访客快速辨认产品，并顺畅阅读产品详情。英文使用本地 Inter Variable，中文优先使用 macOS 苹方，其他平台使用系统中文字体回退。Inter 文件来自项目已有预览，原文件 SHA-256 一致，附 SIL Open Font License 1.1；正式页面预加载本地字体。

## 排版决定

- 首页、关于标题与产品名称使用 500 字重；取消首页标题局部 700 加粗，中文字距由紧密收至轻微负字距。
- 首页展示标题在桌面为 44–64px；弹框标题为 34–42px，采用 1.3 行高。320px 首页标题为 28px，保持一行完整显示。
- 主要正文在桌面为 15px；中文说明采用 1.85–1.9 行高，产品事实、按钮与返回入口同步提高可读性。
- 英文产品名、顶部导航、Dock 与详情标签统一字体和字重层级；窄屏详情标签保持完整，点击高度维持 44px。
- 本轮不修改文案、产品品牌图标、演示内容、颜色、拨牌几何或交互脚本；保留此前移除的 Dock 总览、弹框外边框与顶部分隔线。

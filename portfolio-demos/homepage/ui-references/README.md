# 年度最佳 UI：文字与按钮参考

2026-10-10，按用户要求研究 5 个不同网站，严格采用 CSS Design Awards 年度评选的 Best UI Site 获奖者：2025 Exat Typeface、2024 Cartier Watches and Wonders 2024、2023 Unseen Studio、2022 Jimmy Nelson、2021 Prometheus Fuels。每个奖项均已核对当年的官方获奖公告，使用奖项所属年度，不以公告发布日期替代。并非以日奖、月奖、普通 Best UI Design 票选或年度提名充当年度 UI 获奖。

`index.html` 为独立参考页，未修改正式首页。`sources.json` 记录官网、年度公告、CSSDA 历史收录画面、可见细节分析及对本首页的设计建议。三张历史画面均从官方年度项目页面原始 HTML 中提取，直接引用 CSSDA 公共图片地址，未下载或改写品牌素材。画面已标明获奖版本，不能当作当前官网的实时截图。各官网可能改版，Cartier 为有年份的专题作品。

官方年度公告分别发表于 2026-02-12、2025-02-18、2024-02-20、2023-02-15、2022-02-25。每一篇的 Best In Class Winners 中明确列出了对应的 Best UI Site。

形态和排版分析基于 15 张 CSSDA 收录画面的实际浏览，以及项目官网和设计方的说明。Exat 实时官网在浏览器读取中超时，改为核对历史版本图片；未宣称实际完成五站的悬停、按下或触摸测试。文中的微交互是适配本首页的建议，尚未实装。

参考页验证：正常桌面视口 1280×720 和 375×812 手机宽度下无页面水平溢出，五个案例标题无横向溢出。15 张不同的官方收录图片均加载成功；五个方案跳转入口以及展开补充图片的操作正常。恢复浏览器正常尺寸后保留参考页，正式首页资源同步检查通过。

根目录 `index.html` 是首页真源。`portfolio-demos/demo-a-macos-desktop.html` 是保留的旧入口，除 `<base href="../">` 外内容与真源一致。两个入口共享此目录中的样式、脚本和截图。资源使用相对路径，兼容 GitHub Pages 的仓库子路径。部署直接上传根目录首页，不再以旧页面覆盖。

修改页面或此目录中的 CSS/JS 后，运行：

```sh
python3 scripts/sync-homepage.py
python3 scripts/sync-homepage.py --check
```

同步脚本更新资源内容哈希和旧入口；部署前检查两者一致。`index.html` 已从 `.gitignore` 中移除，需与首页资源、同步脚本及部署配置一同提交。

`catalog.js` 中的 `products` 是产品资料真源；卡片、详情标签和浏览顺序据此生成。新增真实产品即可扩展牌组，不根据 URL 数量生成占位。`featured: true` 控制 Dock 的精选入口，最多四个。图片、图标、产品页和演示路径均从站点根目录解析。

`fan.js` 只实现选定的 C 布局。鼠标拖动和触摸 Pointer Events 共用拨牌逻辑，一次最多前进或后退一张；两侧卡片点击居中，主卡点击打开详情。方向键逐张浏览，Home / End 到首尾；保留隐藏操作说明、当前作品播报和焦点返回。遵循系统减少动效偏好。没有自动轮播或纵向滚轮劫持。

详情底部不再显示“上一款 / 下一款”导航或对应留白，产品切换通过顶部标签和键盘左右方向键完成。

首次打开默认为深色；用户手动选择的主题保存到 `xiaofeng-homepage-theme`，与独立预览的主题设置分开。`motion.js` 提供 Dock、窗口展开与返回动效；`site.js` 提供详情、主题和演示播放。打开详情或切换产品时自动加载并播放该产品的演示，MindMap 视频默认静音、内联循环播放；首页总览不加载演示。演示下方不再显示播放状态或停止按钮，也不保留该行占位。视频原生控件仍可操作，浏览器限制自动播放时保持视频及原生播放入口可用；切换或关闭会移除旧 iframe 或暂停旧视频。详情转场支持当前图片、iframe 和视频，自动开始演示不会取消窗口展开动效。

# 导航图标来源

来自官方 [phosphor-icons/core](https://github.com/phosphor-icons/core)，Regular 线性图标，2026-10-10 下载，SVG 未修改。遵循随附 `LICENSE` 中的 MIT 许可。

官方源路径为 `https://raw.githubusercontent.com/phosphor-icons/core/main/assets/regular/`：

- `clipboard-text.svg`：Repaste 导航符号。
- `speaker-high.svg`：Readless 导航符号。
- `tree-structure.svg`：MindMap AI 导航符号。
- `list-checks.svg`：WidgetToDo 导航符号。
- `arrow-up-right.svg`：卡片打开详情的方向提示。
- `arrow-right.svg`：按钮水平箭头，2026-10-10 从同一官方 Regular 目录下载，SVG 未修改。

目前首页卡片及详情主按钮统一引用 `arrow-right.svg`，使用同一尺寸、颜色继承与水平位移动效。`arrow-up-right.svg` 及其余四个图标为之前方案的遗留素材，已不引用。卡片、Dock 与详情统一使用 `catalog.js` 中的原产品 `icon`；新增产品须提供产品本身的品牌图标。
